Problemas y Soluciones Técnicas

Registro documentado de incidencias reales encontradas en desarrollo web, scripts de Node.js y administración de servidores.

Incidencia #1

Error 403.14 - Listado de Directorios Deshabilitado en IIS

Al desplegar un nuevo sitio web en Windows Server / IIS dentro de una carpeta de grupo sin un archivo index.html principal, el servidor rechaza la conexión con error de acceso denegado.

Solución Técnica:

Asegurar la creación correcta del archivo index.html dentro del directorio personal (PrimerNombre_apellido) y verificar en IIS que el "Documento Predeterminado" incluya dicho archivo. Habilitar la característica de exploración de directorios si es estrictamente necesario para prácticas de laboratorio.

Incidencia #2

Unhandled Promise Rejection en Node.js

Falla imprevista en scripts de Node.js al consumir bases de datos o servicios remotos sin capturar correctamente las excepciones asíncronas, provocando detenciones en el servidor backend.

Solución Técnica:

Implementar bloques robustos de try / catch acompañados de sintaxis async/await en todas las consultas de red o E/S de archivos. Agregar un listener global para process.on('unhandledRejection') como red de seguridad.

Incidencia #3

Conflictos de Permisos SMB en Carpetas Compartidas

Miembros de equipo sin privilegios de escritura al intentar crear sus carpetas personales en el servidor remoto asignado durante prácticas de trabajo colaborativo.

Solución Técnica:

Configurar los permisos NTFS en la pestaña "Seguridad" de la carpeta compartida en Windows Server, garantizando que el grupo de usuarios autenticados tenga permisos de "Modificación" y "Lectura/Ejecución" sobre la ruta raíz del grupo.

Incidencia #4

Desbordamiento de Maquetación CSS en Móviles

Elementos visuales y contenedores fijos que causan scroll horizontal no deseado al visualizar páginas web en dispositivos con pantallas reducidas.

Solución Técnica:

Validar la inclusión de la etiqueta <meta name="viewport" content="width=device-width, initial-scale=1.0"> en el <head> y utilizar unidades relativas y clases flexibles basadas en contenedores de ancho fluido con Tailwind CSS.
